# Keyboard Shortcuts

## Global Workstation

| Key | Action |
|-----|--------|
| `Ctrl+P` | Open the command palette |
| `Ctrl+N` | Create a new session |
| `Ctrl+S` | Save the current session |
| `Ctrl+Y` | Copy the last assistant response |
| `Ctrl+C` | Request exit; press twice quickly to quit |
| `Tab` | Cycle focus across sessions, chat, settings, and input |

## Command Palette

| Key | Action |
|-----|--------|
| `Ctrl+P` | Open palette |
| `Up` / `Down` | Move through results |
| `Enter` | Execute the selected command |
| `Esc` | Close palette |

The palette searches commands, recent sessions, installed models, and workspace files with fuzzy matching.

## Pickers

| Key | Action |
|-----|--------|
| `Up` / `Down` | Move through picker results |
| `Enter` | Select the focused item |
| `Esc` | Close picker |

Pickers are available for `/workspace`, `/model`, `/session`, and `/resume` when used without arguments in the Textual workstation.

## Home Screen

| Key | Action |
|-----|--------|
| `Enter` or `Esc` | Enter the workstation session |
| `Ctrl+P` | Open command palette |
| `n` | New session |
| `r` | Resume session |
| `w` | Open workspace picker |
| `m` | Open model picker |
| `s` | Open help/settings reference |
| `1`-`9` | Open a recent session |
